# Flashcard Project

A Python Tkinter app that shows French–English flashcards.

## Features
- Displays French word on the front card.
- Flips to English translation after 3 seconds.
- ✅ button saves known words (removes from list).
- ❌ button skips to next card.
- Words stored in `words_to_learn.csv`.

## How to Run
1. Install requirements: `pip install pandas tkinter`
2. Run `main.py` in PyCharm.
3. Make sure `card_front.png`, `card_back.png`, and `words_to_learn.csv` are in the same folder.
